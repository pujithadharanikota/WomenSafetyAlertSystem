# Women Safety Alert System 🚨

## 📌 Project Overview
The Women Safety Alert System is a Java-based console application designed to help improve women’s safety by allowing users to raise emergency alerts. The system stores user details and alert messages using file handling, making it simple and effective for learning core Java concepts.

This project is suitable for students and beginners and demonstrates how real-world problems like safety can be addressed using programming.

---

## 🎯 Objectives
- To provide a simple emergency alert mechanism
- To practice Java file handling
- To understand object-oriented programming concepts
- To use Git and GitHub for version control

---

## 🛠️ Technologies Used
- Java
- File Handling (Text Files)
- Git & GitHub
- Command Line / Git Bash

---

## 📂 Project Structure
WomenSafetyAlertSystem/
- User.java              → User details and operations
- Alert.java             → Alert generation logic
- SafetySystem.java      → Main program execution
- users.txt              → Stores registered user details (auto-created)
- alerts.txt             → Stores alert messages (auto-created)
- README.md              → Project documentation

---

## ⚙️ How the Project Works
1. When the program starts, the required files (users.txt and alerts.txt) are automatically created if they do not exist.
2. Users are registered with basic details.
3. In an emergency situation, a user can trigger an alert.
4. Alert messages are saved into alerts.txt.
5. User details are stored in users.txt for future reference.

---

## 👩‍💻 Who Uses This System?
- Users (Women): Trigger emergency alerts.
- Authorities/Admin (conceptual): Can view alert records stored in files.

## 🚀 How to Run the Project
1. Open the project folder in VS Code or any Java IDE.
2. Compile the program:
   javac SafetySystem.java
3. Run the program:
   java SafetySystem
